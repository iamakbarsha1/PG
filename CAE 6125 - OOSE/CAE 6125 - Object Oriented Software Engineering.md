2. Water fall Model
	1. Steps:
		1. Requirement Analysis
		2. System Design
		3. Implementation
		4. Development
		5. Testing
		6. Maintenance
	2. Adv.
		1. Simple to Implement
		2. Used when the requirement is well stable and well understood
	3. Dis Adv.
		1. Sequential Dev will be hard (like new changes to be made)
		2. Implementing changes at later will be difficult.
3. Spiral Model
	1. An iterative and incremental model.
	2. Adapts the Water fall model
	3. contains 4 phases:
		1. Determine objectives
		2. Alternatives
		3. Constraints
		4. Planning phase
	4. Adv.
		1. Changes in each stage can be implemented easily
		2. Risk identification at an early stage
	5. Dis Adv.
		1. Based on Customer centric software dev. Miss communication may result in great problem
